# Generated Testnet & Proving Artifacts Policy

**Status: prototype.** Setu runs against the Stellar **testnet** with a local single-contributor Groth16 setup (`not production-secure`). This document separates **checked-in repository fixtures** from **generated local/testnet build artifacts** that must be cleaned before release packaging.

## 1. Checked-In Fixtures (Tracked in Git)

The following files are small, deterministic test vectors required for `cargo test` without running a full `circom` / `snarkjs` ceremony:

| Path | Purpose | Contains Secrets? |
| --- | --- | --- |
| `libs/zk/testdata/public_signals/withdrawal.json` | Pinned public signal ordering fixture for `circuits/main.circom` | No (public signals only) |
| `libs/zk/testdata/public_signals/disclosure.json` | Pinned public signal ordering fixture for `circuits/disclosure.circom` | No (public signals only) |
| `libs/zk/testdata/receipt_tags.json` | Deterministic `auditorTag` / `discloseHash` vector | No (test vector only) |
| `site/auth-config.example.js` | Template showing expected `SETU_SUPABASE_CONFIG` shape | No (placeholder values) |

## 2. Generated Local & Testnet Artifacts (Ignored / Cleaned Before Packaging)

The following directories and files are produced during local circuit compilation, single-party proving setup, or local site runs and must **never** be committed or bundled into a source release:

| Path / Pattern | Generated By | Why Excluded |
| --- | --- | --- |
| `output/` | `run.sh`, `setup.sh`, `generate_proof.sh` | Contains local `.ptau`, `.zkey`, `.wtns` witness files, and temporary coin secrets |
| `circuits/build/`, `circuits/disclosure_build/` | `circom` compilation | Large intermediate `.r1cs`, `.sym`, and WASM witness generators |
| `*.zkey`, `*.ptau`, `*.wtns` | `snarkjs` | Local single-contributor toxic waste / private witness state |
| `site/auth-config.js`, `.env`, `site/.env` | `node site/build-config.cjs` | Deployment-specific Supabase URL / anon key configuration |
| `target/` | `cargo build` / `stellar contract build` | Rust compilation cache and intermediate build outputs |

## 3. Pre-Release Cleanup Command

Before cutting a release archive or verifying a clean working tree, run:

```bash
# Verify no generated artifacts are present:
node scripts/clean-artifacts.cjs --check

# Remove generated local artifacts:
node scripts/clean-artifacts.cjs --clean
```
